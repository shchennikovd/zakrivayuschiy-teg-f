# Закрывающий тег

Интерактивная веб-страница с карточками, анимациями лайков и модальным окном.  
Проект демонстрирует работу с современным CSS, SVG-анимациями и доступностью интерфейса.

## Демо
https://shchennikovd.github.io/zakrivayuschiy-teg-f/

## О проекте

Страница состоит из карточек с воспоминаниями о начале обучения разработке.  
Каждая карточка содержит интерактивную кнопку лайка с анимацией сердца и кнопку сохранения.

Проект демонстрирует:

- работу с **SVG-анимациями**
- **CSS transitions и transforms**
- **доступность интерфейсов (focus-visible)**
- управление **модальными окнами через JavaScript**

## Функциональность

- анимированная кнопка лайка  
- кнопка сохранения карточки  
- модальное окно  
- анимации интерфейса  
- поддержка доступности (a11y)

## Технологии

- HTML5
- CSS3
- JavaScript
- SVG
- BEM методология
